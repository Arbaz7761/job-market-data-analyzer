# Global Data Job Market Analysis

This project analyzes the global data job market using Python and Power BI.

## Tools Used
- Python
- Pandas
- Power BI

## Dataset
The dataset contains information about data science jobs, salaries, experience level, and remote work.

## Insights
- Top 10 Most In-Demand Data Jobs
- Average Salary by Experience Level
- Remote vs Onsite Jobs Distribution
- Top 10 Highest Paying Data Jobs

## Dashboard
A Power BI dashboard was created to visualize the job market trends.
